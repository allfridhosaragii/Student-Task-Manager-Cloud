=== AUDIT & REMEDIASI KEAMANAN DOCKER SOCKET ===
Waktu Remediasi: 2026-10-25 19:01:05 UTC (02:01 WIB)
Target VM: Azure Virtual Machine 'edo-praktikum2' (70.153.150.99)
File Socket: /var/run/docker.sock

1. IDENTIFIKASI RISIKO:
Sebelumnya socket sempat diubah ke 666 (world-writable), yang membuka celah keamanan bagi pengguna lokal non-privilege untuk mengendalikan Docker daemon.

2. TINDAKAN REMEDIASI HARDENING:
Perintah:
sudo chown root:docker /var/run/docker.sock
sudo chmod 660 /var/run/docker.sock
sudo usermod -aG docker azureuser

3. HASIL VERIFIKASI PERMISSION & GROUP:
Perintah: ls -la /var/run/docker.sock
Output:
