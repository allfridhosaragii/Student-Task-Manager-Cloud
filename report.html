2. ARSITEKTUR DAN TEKNOLOGI SISTEM

Aplikasi Student Task Manager mengimplementasikan arsitektur multi-service terisolasi:

  • Service Application (app): Node.js v20 Alpine dengan Express.js yang melayani RESTful API dan antarmuka web modern. Dipetakan ke port 80 pada host Azure VM.
  • Service Database (database): PostgreSQL 16 Alpine yang berjalan pada internal network student_task_backend tanpa membuka port ke host atau internet. Data disimpan persisten pada named volume postgres_data.
