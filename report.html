2. ARSITEKTUR DAN TEKNOLOGI SISTEM

Aplikasi Student Task Manager mengimplementasikan arsitektur dua service terisolasi:

  • Service Application (app): Node.js v20 Alpine dengan Express.js yang melayani RESTful API dan antarmuka web modern. Dipetakan ke port 80 pada host Azure VM.
  • Service Database (database): PostgreSQL 16 Alpine yang berjalan pada internal network student_task_backend tanpa membuka port ke host atau internet. Data disimpan persisten pada named volume student_task_postgres_data.
  • Service Test Runner (test-runner): Kontainer pengujian terisolasi yang diaktifkan dengan profil --profile test untuk menguji CRUD langsung pada database PostgreSQL tanpa mock.
